📋 Workflow Checklist

Use this simple checklist to get your first game running:

  1. ✅ Download – Get the latest DOSBox setup from this repository.
  2. ✅ Install – Run the installer (default settings are fine).
  3. ✅ Create a folder – For your games, e.g., C:\DOSGAMES.
  4. ✅ Launch DOSBox – Open the program from your desktop.
  5. ✅ Mount the folder – In the DOSBox window, type:
    mount c C:\DOSGAMES and press Enter.
  6. ✅ Switch to C: – Type c: and press Enter.
  7. ✅ Run your game – Type the game’s filename (e.g., game.exe) and press Enter.
  8. ✅ Log your session – Keep notes in a text file for future reference.
